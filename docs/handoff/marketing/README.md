## Estado y límites
Los seis expedientes Marketing no se localizaron como archivos independientes íntegros. Los Markdown son extractos de transferencia de las especificaciones disponibles en conversación y entrega anterior, no transcripciones completas ni sustitutos de originales. Solicitar textos íntegros si una decisión no está cubierta. No se recuperó informe final Comercial ni documentación de validación Fase 01. No se incluyen SVG original, fuentes binarias, licencias de versiones, fotografías independientes de Inicio o catálogo ni textos institucionales definitivos. No inventarlos. Los PNG y DOCX se preservan sin edición. El catálogo JSON se extrae del DOCX; P-011 aparece como tarjetas en ficha y unidades en matriz general: mantener la discrepancia para Comercial. Las cantidades mínimas no están confirmadas. Usar placeholders identificados para recursos faltantes. No publicar hasta validaciones correspondientes.
